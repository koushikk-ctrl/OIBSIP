# ATM Interface Using Java

## About the Project

This project is a simple ATM Interface developed using Java. It allows users to perform basic banking operations through a menu-driven program.

## Features

* Check account balance
* Deposit money
* Withdraw money
* Exit the application
* Validate deposit and withdrawal amounts

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Scanner class
* Switch statement
* Do-while loop

## Project Structure

* `Main.java` — Starts the application.
* `ATM.java` — Displays the menu and handles user choices.
* `Account.java` — Manages the account balance, deposits, and withdrawals.

## Initial Balance

The account starts with a balance of Rs. 1000.

## How to Run

1. Download all three Java files.
2. Open them in NetBeans or another Java IDE.
3. Run `Main.java`.
4. Select an option from the ATM menu.
